# 放映胶片核对台

给放映员和档案整理人员使用的纯前端本地工具：按胶片卷整理片段、调整放映顺序、登记颜色偏移与破损情况、实时统计总时长与风险，并导出试映清单。

完全离线可用，无需安装任何东西：直接双击打开 `index.html` 即可（也可以在本目录启动静态服务访问）。所有数据保存在本机浏览器的 localStorage 中，刷新、关闭重开都不会丢失。

## 功能

- **多胶片卷管理**：新建、切换、重命名、删除胶片卷；每卷独立保存片段清单、顺序和卷备注。
- **片段录入与编辑**：编号、时长（支持 `95` 或 `1:35` 格式）、颜色偏移、破损情况、缩略图、备注。
- **录入校验**（不通过则明确提示、不写入清单）：
  - 编号为空或与本卷已有片段重复；
  - 时长为空、非数字、为零或负数、超出 24 小时；
  - 缩略图格式不支持（仅 PNG/JPG/WebP/GIF）、超过 2MB、或文件损坏无法解码。
- **排序**：拖拽卡片或点 ↑ ↓ 按钮调整放映顺序（筛选状态下排序自动锁定，避免误操作）。
- **筛选**：按颜色偏移、破损情况、编号/备注关键词组合筛选。
- **实时统计**：片段数、总时长、高风险/需留意数量，风险提醒面板逐条列出问题片段；单卷超过 60 分钟给出片长提醒。
- **误删恢复**：删除片段或整卷后可通过提示条「立即恢复」或顶栏「恢复最近删除」找回（保留最近 20 条删除记录，刷新后依然有效）。
- **导出与备份**：
  - 试映清单 CSV（带 BOM，Excel 直接打开不乱码，含风险列）；
  - 全部数据 JSON 备份，可在其他机器上「导入备份」恢复。
- **缩略图**：上传后自动压缩为 ≤360px 的 JPEG 存入本地，避免占满存储空间。

## 风险分级

| 级别 | 颜色偏移 | 破损情况 |
| --- | --- | --- |
| 高风险 | 严重褪色 | 齿孔破损、片基脆化、霉变、需跳过 |
| 需留意 | 偏红、偏青、偏黄、褪色 | 轻微划痕、接片松动 |

片段风险取两者中较高者。

## 使用提示

- 首次打开会看到一个「示例卷」，熟悉操作后可直接删除。
- 数据只存在当前浏览器中；换电脑或清理浏览器数据前，请先「备份全部数据」。
- 清理浏览器站点数据会清空全部清单，重要场次建议导出 CSV 留底。
